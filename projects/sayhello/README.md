# SayHello

Say hello to the world.

## Installation

Clone:

```
$ git clone https://github.com/uganh16/learn-flask.git
$ cd learn-flask/projects/sayhello
```

Create & activate virtual env then install dependencies:

```
$ pipenv install --dev
$ pipenv shell
```

Generate fake data then run:

```
$ flask forge
$ flask run
 * Serving Flask app 'sayhello'
 * Debug mode: on
 * Running on http://127.0.0.1:5000
```
